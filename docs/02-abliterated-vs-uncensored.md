# DeepSeek Abliterated vs. Uncensored

“DeepSeek abliterated” and “DeepSeek uncensored” are related but not interchangeable. Abliteration is a weight-level technique; “uncensored” describes the broader outcome.

## Definitions

**DeepSeek abliterated** — weights modified to reduce the model’s refusal direction.

**DeepSeek uncensored** — a variant that refuses less often, whether through abliteration, fine-tuning, merging or prompting.

## Side-by-side

| | Abliterated | Uncensored |
|---|---|---|
| **What it describes** | A weight-level technique | An observable behavior |
| **Typical effect** | Strong reduction in refusals | Reduced refusals, varies by recipe |
| **Best for** | Experiments where refusal is the blocker | Research, creative and agent work |
| **How to verify** | Test the exact model ID | Test the exact model ID |
